# DENIC RRI 5.0 XML schemas

Copied verbatim from the DENIC documentation, retrieved 2026-11-11:
<https://docs.denic.de/en/Content/Beispiele/50/XMLSchema/Overview-XMLSchema.htm>

DENIC publishes the schemas as code listings on one page per schema, not as files. The file names are the ones the
schemas use in their `schemaLocation` imports. `global-5.0.xsd` (`registry-request`, `registry-response`) is the
entry point and compiles with all imports resolved.
